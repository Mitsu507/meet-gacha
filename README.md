# 🎲 약속 장소 가챠 (기획 프로토타입)

> 친구들과 어디서 밥 먹을지 / 어디서 놀지 고민될 때, **질문 3개**로 조건에 맞는 곳을 **3~5곳** 뽑아주는 앱

**👉 바로 써보기: https://mitsu507.github.io/meet-gacha/** (폰에서 열면 앱처럼 보여요)

지금은 기획 단계라 결과를 보면서 계속 고칠 예정인 웹 프로토타입이에요.

---

## 사용 흐름

```
[위치 설정] → [누구랑?] → [목적] → [예산/스타일] → [오늘 뺄 것] → 🎲 3~5곳 결과
```

| 단계 | 내용 |
|---|---|
| 1. 위치 | 📍 내 위치 / 검색 / 지도 누르기. **친구들 중간지점** 모드면 출발지 2~4곳을 찍으면 중간에서 찾음 |
| 이동 거리 | 걸어서 10분(800m) / **대중교통 20분(4km, 기본)** / 차 타고 멀리(10km, 주차 정보 우대) |
| 2. 누구랑? | 혼자 / 연인·데이트 / 친구들 → 등록한 친구를 고르면 **취향·싫어하는 것이 자동 적용**, 인원수 |
| 3. 목적 | 든든한 밥 / 카페·디저트 / 술자리 / 놀거리 |
| 4. 예산·스타일 | 가성비 / 적당히 / 특별한 날 (놀거리면: 엔빵 부담 없게 / 다 같이 신나게 / 오래 앉아 수다) |
| 5. 오늘 뺄 것 | 해산물·매운음식 등 오늘만 빼고 싶은 것 + ☔ 실내만 |
| 결과 | 지도에 번호 핀 + 카드. **추천 이유** 표시, 길찾기(카카오맵), 후기(네이버지도), 🚫 블랙리스트 |
| 다시 뽑기 | 기본 3번 (설정에서 2~3번). 이미 본 곳은 다시 안 나옴 |

### 1차 회의 반영 사항
- [x] 1곳 → **3~5곳** 한 번에 추천 (설정에서 개수 변경)
- [x] **친구 취향 기억**: 이름만 고르면 좋아하는 것(가중치↑)·싫어하는 것/알레르기(제외) 자동 적용
- [x] 질문 수정본 (누구랑 / 목적 / 예산·스타일)
- [x] **재가챠** 2~3회 제한
- [x] **블랙리스트** (나만 적용)
- [x] **추천 이유** 설명 (예: `민수가 싫어하는 '해산물' 제외 완료`, `중간지점에서 대중교통 약 15분`)
- [x] 친구들 **중간지점** 찾기 (초기 아이디어의 차별화 포인트)

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (지도, 바텀시트, 하단 탭) |
| `logic.js` | 추천 로직: 태그 판정, 필터링, 점수, 가챠 |
| `test.js` | 로직 점검 `node test.js` |

- 지도: Leaflet + OpenStreetMap
- 장소 데이터: OpenStreetMap Overpass API (키 필요 없음, 무료)
- 위치 검색: OpenStreetMap Nominatim
- 친구·블랙리스트·설정: 브라우저(localStorage)에 저장 → 기기마다 따로

## 알려진 한계 / 다음에 할 것
- **평점·후기·영업시간·가격 정보가 약함**: OSM엔 평점이 없음 → 카카오 로컬 API로 바꾸면 해결 (API 키 + 서버 프록시 필요)
- **이동시간은 직선거리 추정**: 실제 대중교통 시간은 길찾기 API 필요
- **중간지점은 좌표 평균**: 대중교통 기준 "공평한" 중간은 경로 API 필요
- **휴무 판별 없음**: 지금은 재가챠로 대응
- 소음/주차/콜키지 같은 상황 필터는 데이터가 생기면 추가
- 친구 정보 기기 간 공유 (로그인/서버 필요)
